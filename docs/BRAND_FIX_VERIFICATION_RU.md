# Цвет, маршрут и восстановление прогресса

База: `661d53a` — завершённые изменения параллельного агента (новый маршрут,
регистрация, 117 упражнений). Правки готовились в отдельных worktree; исходный
checkout `/Users/skebobr/Desktop/Espada` не изменялся.

## Дизайн

- Основной цвет `#336945`: медиана зелёных пикселей фактического
  `assets/brand/knight-light.jpg` (RGB 51, 105, 69).
- Светлая тема: белый текст на основном цвете, контраст 6,47:1.
- Тёмная тема: осветлённый зелёный `#7EB792`, текст `#102B1A`, контраст 6,56:1.
- У кружка маршрута теперь равномерная рамка 2 px, нижний объём — отдельная
  тень 5 px. Ободок занимает постоянные 3 px даже у неактивных уроков:
  переключение текущего урока больше не меняет размер поверхности.
- В браузере проверены ширины 1111, 390, 320 px, светлая и тёмная темы.
  Измеренное смещение центров круга и ободка — 0 px по обеим осям;
  при 320 px горизонтального переполнения нет.

## Исправленные функциональные дефекты

1. Ошибка чтения отметок → на главной нажать «Повторить». Раньше повтор
   запускал запись первоначального пустого объекта и мог стереть существующие
   отметки. Теперь он повторяет чтение; запись до успешной загрузки запрещена.
   В каталоге также появилась кнопка повторной загрузки. Простое переоткрытие
   урока не помогало, поскольку хранилище живёт на уровне аккаунта.
2. Открыть упражнения до завершения асинхронной загрузки сохранённых ответов.
   Раньше начальный индекс вычислялся по пустому состоянию и оставался на
   первом задании. Теперь после загрузки один раз выбирается первое
   непроверенное задание; дальнейшие переходы пользователя не сбрасываются.

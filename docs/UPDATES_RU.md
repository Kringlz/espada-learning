# Русская версия и видеоуроки — 24 сентября 2026

В приложении доступны 108 тем из предоставленного PDF, в исходном порядке, объединённые в 22 раскрывающихся раздела. В дереве есть поиск по названию и номеру, состояния изучения тем и количество видео. Все темы можно открыть.

## Как добавить видео

1. В демо откройте меню аккаунта справа вверху и выберите **Марию Соколову** (преподаватель) или **Анну Белову** (администратор).
2. Откройте **Программа**, раскройте раздел и выберите тему.
3. Нажмите **Загрузить видеоурок**, выберите MP4, укажите название и нажмите **Добавить к теме**.
4. Переключитесь на ученика, например **Алексея Морозова**, и откройте эту тему через **Дерево тем → Смотреть видео**.

К одной теме можно добавить несколько видео. Лимит одного файла — 50 МБ. Рекомендуемые кодеки: H.264 и AAC. Файлы не перекодируются; расширение MP4 само по себе не гарантирует совместимость кодеков. При ошибке воспроизведения показывается сообщение и кнопка повтора.

В браузере есть русские кнопки воспроизведения, паузы и возврата к началу; перемотка, громкость и полный экран доступны через системные элементы плеера. Их язык зависит от браузера/ОС. На iOS и Android используется системный плеер Expo Video.

Позиция каждого видео сохраняется отдельно для каждого ученика примерно каждые пять секунд и при паузе. Просмотр не создаёт результат проверки и не повышает оценку знаний. После просмотра новых тем без подготовленных заданий искусственная проверка не предлагается.

## Где хранятся данные

**Локальное демо:** сведения об уроках и результаты — в хранилище приложения; видео — в IndexedDB браузера или в постоянной папке мобильного приложения. Файлы остаются после перезапуска. Другой браузер, адрес сайта или устройство имеет отдельное хранилище. Очистка данных приложения удаляет локальные файлы. Ученики в одном демо видят видео, загруженные преподавателем на том же устройстве.

**Подключённая версия:** приватный бакет Supabase `lesson-videos`. Загружать и прикреплять видео могут только активные преподаватели и администраторы. Ученики могут читать только опубликованные видео после авторизации. Подписанная ссылка действует до шести часов; отключение аккаунта запрещает получение новых ссылок, уже выданная ссылка истекает по своему сроку. Публикация проверяет владельца, путь, MIME и размер фактически загруженного объекта. Повторная отправка не создаёт дубликат урока. Незавершённую публикацию можно повторить, пока страница открыта. После закрытия страницы не прикреплённый файл может остаться в хранилище и потребовать очистки оператором.

## Сохранение прежнего прогресса

Обновление не сбрасывает попытки, письменные работы, баллы и назначения. Девять существующих учебных тем связаны с соответствующими пунктами списка; три дополнительных материала сохранены отдельно. Идентификаторы и индексы правильных ответов не меняются. Перевод заменяет только исходные демонстрационные тексты, сохраняя авторские изменения.

В новой программе подготовлены места для всех 108 тем. Полный цикл объяснение → практика → проверка по-прежнему содержится в 12 исходных материалах; 99 новых тем ожидают материалов преподавателя. Самих учебных видеозаписей PDF не содержит. В текущем локальном демо в теме 2 оставлен явно обозначенный короткий **тест плеера**, использованный для проверки загрузки, а не учебный урок.

## Подключение обновления к серверу

Примените миграции `001_learning.sql`, `002_russian_curriculum.sql`, `003_topic_videos.sql` по порядку. Для существующей базы с первой миграцией применяются только вторая и третья. Затем примените `supabase/seed.sql`: добавление пропускает уже существующие записи. Не запускайте тестовые фикстуры на реальном сервере.

Реальный Supabase-проект в этой сессии не создавался и не изменялся. Проверка загрузки через облачный Storage и запуск на физических iOS/Android-устройствах остаются этапами перед использованием с учениками.

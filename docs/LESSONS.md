# Уроки в текущем приложении

Рабочие исходники: src/lessons/, src/course/videoLesson/ и content/.
Определение схемы: supabase/migrations/. Настройки подключения: .env.example.
Карта фактического интерфейса: CURRENT_APP.md.

Прежняя подробная инструкция импорта сохранена в
АРХИВ/история/docs/LESSONS.md. Она содержит исторические пути локальных
баз и старые названия разделов: не используйте их как актуальное окружение.
Формат импорта проверяйте по текущему коду src/lessons/ и тестам.

Проверка приложения: npm run check. Команды локальных проверок уроков
перечислены в package.json. Они не означают публикацию или изменение рабочей базы.

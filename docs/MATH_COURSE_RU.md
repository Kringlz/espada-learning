# Курс математики 5–11 классов

Курс открывается по умолчанию в **Учёба → Курс 5–11 классов** у ученика и в **Программа → Курс 5–11 классов** у преподавателя и администратора.

## Состав

Программа следует распределению по классам, которое передал заказчик. Отрицательные числа остаются в 5 классе, векторы — в 8 классе. Формулировки названий взяты из оглавлений PDF; сокращения в них не меняют состав тем.

## Как пользоваться

1. Выберите класс и предмет; поиск работает по названию и коду темы. Для поиска по всему курсу выберите «Все классы».
2. Откройте тему. Содержание позволяет перейти к конкретной странице. Конспект разделён на небольшие части; кнопки «Назад» и «Далее» сохраняют место чтения.
3. Кнопка «Прочитано» отмечает текущую часть и открывает следующую. Последняя ведёт к самопроверке.
4. Решите задания в тетради или оставьте запись в поле «Мои записи к решению». Подсказки и ответы открываются отдельно.
5. Сравните решение с ответом, отметьте задания «Разобрался» или «Повторить». Эти отметки можно менять.
6. В разделе «О конспекте и источниках» указаны страницы оригинала и библиографическая справка. В веб-версии можно открыть исходный PDF.

Конспекты представлены выделяемым текстом в общем оформлении приложения. Абзацы переносятся по ширине экрана, примеры выделены белыми карточками с золотистым краем, правила — светло-зелёными блоками. Таблицы состоят из текстовых ячеек; широкие таблицы прокручиваются внутри своего блока.

Формулы с верхними и нижними индексами, составные дроби и вычисления столбиком также представлены текстом. Веб-версия использует элементы `sup` и `sub`; на iOS/Android применяются соответствующие символы Unicode, а для неподдерживаемых сочетаний — однозначная запись со скобками. Графики и геометрические чертежи сохранены как 34 отдельные иллюстрации. Текст вокруг них, включая подписи-пояснения, доступен для выделения.

## Сохранение и оценки

Закладки, прочитанные страницы, записи и отметки сохраняются через AsyncStorage с отдельным ключом профиля `espada.math-course.v1:<profile-id>`. На вебе это хранилище браузера. Данные доступны на этом устройстве и в этом браузере; синхронизации между устройствами для этого курса пока нет. Сбой сохранения отображается явно, доступна повторная попытка. Повреждённые сохранения не перезаписываются автоматически.

Самопроверка не выставляет баллы и не меняет освоение тем, оценки учителя или результаты независимых тестов. Исходные задания включают доказательства, графики и построения; простой поиск совпадающей строки не был бы корректной автоматической проверкой. Автоматические тесты по каждой из 55 тем потребуют отдельно подготовленного банка и критериев.

Существующие серверные «Уроки и тесты» остаются отдельной вкладкой. Старое дерево из 108 пунктов находится в «Дополнительных материалах». Старые ID тем, задания, видео, домашние работы и история результатов сохранены; новый каталог не делает неподтверждённого переноса освоения между разными программами. Новый курс доступен без подключения Supabase, также в подключённом режиме. Его локальные отметки не отображаются в отчётах преподавателя.

## Обновление материалов

- `content/math-course/grade-05.pdf` … `grade-11.pdf`: точные копии исходников.
- `content/math-course/sources.json`: контрольные суммы, число страниц и тем.
- `content/math-course/catalog.json`: каталог, страницы, названия, ссылки на задания и источники.
- `content/math-course/structured.json`: текстовые блоки, формулы, таблицы, примеры, задания, подсказки и ответы.
- `content/math-course/figures/`: только графики и чертежи в PNG.
- `content/math-course/extraction-audit.json`: проверка распределения символов исходника по блокам; колонтитулы и библиографические справки обрабатываются отдельно.
- `scripts/extract-math-content.py`: восстановление структуры текста, индексов, дробей, таблиц и вычислений столбиком.
- `src/course/`: каталог, чтение и хранение личных отметок.

Для повторного импорта нужны Python, pypdf, pdfplumber, pypdfium2 и Pillow:

```sh
python scripts/import-math-course.py /папка/с/семью/PDF
npm run check
GITHUB_PAGES_BASE_PATH=/espada-learning npm run build:pages
```

Импорт использует оглавления и реальные границы текста, сохраняет исходную графику, разделяет ответы и вопросы. Повторный запуск обновляет и каталог, и текстовые блоки. Структурный перенос не заменяет методическую проверку математического содержания. В A05-04 внутри исходного PDF указан старый код «01 · ЧИСЛА», а библиографической ссылки нет; код A05-04 взят из оглавления, источник не выдумывается. Исходные PDF не редактировались.

Сгенерированные материалы включены в проект, поэтому сборка и CI не зависят от Python или папки Downloads. Сборка выполняется локально; публикация происходит отдельно по существующему процессу проекта.

# Работы и изучение тем

## Для ученика

На **Главной** сначала показано **Домашнее задание**, затем **Последняя работа**, **Продолжить учёбу** и **Что повторить**. Оценка учителя отмечена словом «Оценка». «Посмотреть результаты» сразу открывает эту работу; «Все работы» — историю. Непросмотренный результат отмечается как новый, включая исправленную учителем версию.

В **Прогрессе** два отдельных раздела:

- **Результаты работ:** оценки, даты, правильные ответы по разделам, диаграмма и сравнение с выбранной предыдущей работой. При длинной истории доступен поиск по названию/дате и фильтр шаблона. Данные старого формата сохранены в «Архиве прежних работ с баллами».
- **Изучение тем:** состояния тем, фильтры по состояниям и счётчик освоенных тем из 108. Общий результат по разделу не выдаётся за освоение каждой темы.

Сравнение «Было 50% → стало 70%» относится к результатам работ. Сложность работ может отличаться. Пропущенный результат означает «Нет данных», а не ноль. Если измерено меньше трёх разделов, вместо диаграммы используется понятный список. Полную историю по разделам можно раскрыть отдельно.

В **Учёбе** открыты все 108 тем, поиск и видеоуроки. Возврат из урока или результата сохраняет выбранный список, фильтры и положение прокрутки в текущем сеансе. Перезагрузка приложения начинает с главной; учебные данные и позиция видео сохраняются.

## Для преподавателя

1. **Работы → Новый шаблон.** Укажите название, минимальную/максимальную оценку и шаг. Для каждого раздела задайте название, содержание проверки и связанные темы из программы.
2. По умолчанию результат относится только к разделу. Только если самостоятельная проверка действительно полностью покрывает одну тему, выберите соответствующее подтверждение. Общая работа не должна отмечаться как проверка каждой связанной темы.
3. **Добавить результат.** Выберите ученика, нужную версию шаблона, дату и оценку. Для каждого раздела заполните «Правильно» и «Всего вопросов». Для отсутствующих данных оставьте оба поля пустыми; для нуля правильных введите 0 и положительное количество вопросов.
4. Сохраните черновик или опубликуйте результат. При исправлении откройте существующую запись и укажите причину — новая работа не создаётся. История изменений сохраняется.
5. Шаблоны неизменяемы. **Новая версия** копирует существующие разделы с их кодами. Изменение их содержания, названия, связей или шкалы начинает отдельную историю сравнения; прежние работы остаются доступны.
6. Обязательное задание назначается в **Ученики → Домашнее задание**. В главной ученика оно отделено от добровольных подсказок.

## Начальные правила освоения

«Ещё не проверяли» — нет самостоятельных ответов. «Изучаю» — они есть, но подтверждений пока мало. «Получается» — последняя проверка минимум из трёх новых вопросов выполнена на 75% или выше. «Освоено» — минимум две проверки на 85% или выше с интервалом не меньше семи дней; последняя также успешна. Повтор тех же вопросов и просмотр видео новых подтверждений не дают.

Это настраиваемые правила первой версии, не научно подтверждённая оценка способностей. Подробности и ограничения — в [описании расчётов](SCORING.md).

## Демо и подключение

Локальное демо дополняется десятью явно обозначенными примерами работ Алексея, включая разные версии и пропуски. Реальные подключённые аккаунты этими примерами не наполняются. Старые данные, видео и попытки сохраняются.

Для существующего сервера после миграций 001–003 примените **004_teacher_reports.sql**. Она добавляет шаблоны, результаты, отметки просмотра и проверяемые сервером операции. Настоящие учётные записи и облачный сервис в этой сессии не создавались. Тестовые фикстуры нельзя применять к рабочему серверу.

# Ресеты приложения

Единственный каталог точек — versions.json. current и previous разрешаются
через метки успешной публикации; контрольные точки закреплены полными
коммитами. main — рабочая ветка, её HEAD может ещё ожидать публикации.

| Имя | Версия |
| --- | --- |
| current | Последняя успешная публикация: release/current |
| previous | Предыдущая успешная публикация: release/previous |
| pre-cosmos | Контрольная до космического интерфейса |
| cosmos-baseline | Начало космического интерфейса |
| before-integration | Перед объединением |
| imported-progress | Снимок импорта прогресса |
| pre-duo | Существующая pre-duo-2026-10-14 |

```sh
git fetch origin '+refs/tags/*:refs/tags/*'
node РЕСЕТЫ/reset.mjs list
node РЕСЕТЫ/reset.mjs current
node РЕСЕТЫ/reset.mjs previous --apply
node РЕСЕТЫ/reset.mjs current --apply
```

Без --apply файлы не меняются. С --apply заменяются исходники приложения,
ресурсы, контент, тесты, серверные исходники и конфигурация пакетов.
Полный список путей печатается перед применением. Инструменты обслуживания,
документация, АРХИВ, РЕСЕТЫ, .env.local и история Git сохраняются.
Это восстановление исходников, а не развёртывание старого окружения: для
очень старой контрольной версии при необходимости используйте инструменты
из того же сохранённого коммита.

До замены существующие файлы из перечисленных путей, включая несохранённые
и неотслеживаемые, копируются в АРХИВ/ресеты/<время>-<имя>/до-ресета.
При ошибке установки скрипт возвращает их обратно. manifest.json фиксирует
исходную и выбранную версии.

Ресет меняет локальные файлы, не ветку и не индекс Git: старая версия будет
видна как локальные изменения. После смены версии выполните npm ci и
npm run check. Сайт, рабочая база, аккаунты и прогресс не сбрасываются;
миграции автоматически не запускаются.

Прежняя отдельная контрольная копия справочника находится в
АРХИВ/контрольные/Espada-reference-20261023. Это архив, не вторая рабочая папка.

Метки release/current и release/previous обновляет только успешная публикация.
Датированные контрольные и архивные метки не передвигаются.

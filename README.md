# Espada — текущее приложение

Единственная рабочая папка: `/Users/skebobr/Desktop/Espada`.
Сайт: https://kringlz.github.io/espada-learning/

**Единственная рабочая и публикуемая ветка — `main`.**
Текущий успешный релиз отмечен `release/current`, предыдущий — `release/previous`.
Точный коммит работающего сайта: [release.json](https://kringlz.github.io/espada-learning/release.json).
Метки обновляются автоматически только после успешного развёртывания.

## Структура

| Путь | Назначение |
| --- | --- |
| `App.tsx`, `src/` | Единственное рабочее приложение |
| `assets/`, `content/` | Ресурсы и учебный материал |
| `supabase/` | Серверные исходники и миграции |
| `scripts/`, `tests/` | Инструменты и проверки |
| `docs/CURRENT_APP.md` | Проверенная карта текущих кабинетов |
| `РЕСЕТЫ/` | Текущая, предыдущая и контрольные версии; восстановление |
| `АРХИВ/` | Все старые макеты, черновики, отчёты, инструкции и копии |

**АРХИВ не описывает текущее приложение.** Он хранится локально, исключён
из обычного поиска, проверки типов, сборки и публикации.

## Кабинеты нельзя путать

Три раздела **«Прогресс / Домашняя работа / Связь с учителем»** в опубликованном
приложении относятся к **родителю (`parent`)**. У учителя (`teacher`) другой
набор разделов. Это не ошибка выбора копии: так реализован опубликованный
релиз. См. [карту приложения](docs/CURRENT_APP.md).

## Запуск

```sh
npm ci
npm run web
npm run check
npm run build:pages
```

Локальное подключение задаёт `.env.local`. Демо и реальный аккаунт — разные
режимы: при проверке указывайте режим, фактическую роль и ширину экрана.
Сборка сама по себе ничего не публикует.

## Установка на Android-доску

1. Подключите доску к интернету и откройте сайт в актуальном Google Chrome.
2. В меню Chrome выберите «Установить приложение» (в некоторых версиях —
   «Добавить на главный экран» → «Установить»).
3. Запускайте **Espada** через иконку с рыцарем. Установленное веб-приложение
   открывается в отдельном окне без вкладок и адресной строки Chrome.

Если ранее был создан обычный ярлык сайта, удалите этот ярлык и установите
приложение заново. Наличие только пункта «Создать ярлык» может означать, что
браузер или прошивка доски не поддерживает полноценную установку. На Android
без сервисов Google поведение зависит от браузера и прошивки; такую доску
нужно проверить отдельно. Системные кнопки Android могут оставаться видимыми.
Внешние ссылки могут открываться с панелью браузера.

Для открытия приложения нужен интернет. При потере сети во время запуска
появляется сообщение «Нет соединения» и кнопка повтора. Офлайн-загрузка уроков
не включена. При следующем открытии HTML запрашивается с проверкой обновлений;
service worker не сохраняет аккаунты, уроки или старые сборки в собственном кеше.

Настройки установки и иконки находятся в `assets/pwa/`. Сборка
`npm run build:pages` подключает их с учётом пути сайта `/espada-learning/`.
Иконки используют существующий логотип `assets/brand/knight-light.jpg`.

## Восстановление

```sh
git fetch origin '+refs/tags/*:refs/tags/*'
node РЕСЕТЫ/reset.mjs list
node РЕСЕТЫ/reset.mjs current
node РЕСЕТЫ/reset.mjs current --apply
```

Без `--apply` файлы не меняются. Перед применением заменяемые исходники
сохраняются в `АРХИВ/ресеты/`. [Инструкция](РЕСЕТЫ/README.md).
